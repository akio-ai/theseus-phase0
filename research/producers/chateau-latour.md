## Overview

✅ **Pauillac 村南東端、Gironde 河口から 300 メートル。畑 96.5 ヘクタール。
そのうち城館を囲む 47 ヘクタールが `l'Enclos`（ランクロ）と呼ばれ、グラン・ヴァンの原料となりうる区画である。**

🔴 ✅ **Château Latour は 3 本のワインを造る。これが本ドシエの中心事実である。**

| # | 公式名 | 位置づけ | 公式ページ |
|---|---|---|---|
| 1 | ✅ **Le Grand Vin de Château Latour** | **グラン・ヴァン。`l'Enclos` の平均樹齢約 60 年の古樹のみ** | `/fr/le-temps-du-partage/le-grand-vin-de-chateau-latour` |
| 2 | ✅ **Les Forts de Latour** | **セカンド。1966 年に初めてこの名で瓶詰** | `/fr/le-temps-du-partage/les-forts-de-latour` |
| 3 | 🔴 ✅ **Le Pauillac de Château Latour** | 🔴 **サード。1989 年から毎年生産。「`le proposer en priorité à la restauration`（飲食店に優先的に供する）」ことを念頭に設計された** | `/fr/le-temps-du-partage/le-pauillac-de-chateau-latour` |

🔴 **第 3 のワインの公式名は、アペラシオン名そのものである。**
**したがってメニューが `Pauillac` と印字したとき、それは「アペラシオンの表示」でも「キュヴェ名の表示」でもありうる。**
**この曖昧さは、他のメドックのシャトーには存在しない。Latour 固有である。**
🔴 **しかも公式は、このサードワインが「飲食店に優先的に供する」目的で設計されたと明記している。
すなわちレストラン・リストに載る蓋然性がもっとも高いワインが、よりによってアペラシオン名を名乗っている。**

## History

✅ **公式沿革ページ（`/fr/le-temps-de-la-creation/depuis-1331`）は静的取得で本文が返る。**

| 年 | 出来事 ✅ |
|---|---|
| 🔴 **1331** | 🔴 **Latour に言及する現存最古の文書。**「**Le document le plus vieux mentionnant Latour date de 1331**」——**Seigneur Pons が Gaucelme de Castillon に対し、Saint-Maubert 教区に稜堡を築く許可を与えた文書**<br>🔴 ⚠️ **公式は「1331 年の文書が最古である」と書いている。「1331 年より前に遡る」とは書いていない。** → §Canonical Conflict `P-9` |
| **1378** | **Jean Froissart の『年代記』に Latour が現れる。**百年戦争の最中、河口を守る要塞「**Tour de Saint-Maubert**」はフランス王のためにブルターニュ兵が守っていた。**3 日間の包囲ののち英ガスコーニュ軍が奪取し守備隊を置く** |
| **〜16 世紀末** | **Latour は共同領主制（co-seigneurie）で、共有者は小作人から地代を受け取っていた。**当時ブドウ畑は全域を覆っておらず、**保存条件が悪くワインはその年のうちに飲まれた** |
| **〜17 世紀末** | **de Mullet 家の所有。**直営が徐々に小作制に取って代わるが、**栽培の状況はほとんど変化しない** |
| **17 世紀末〜** | **相続と婚姻により Alexandre de Ségur の所有となり、メドックに広大な所領が形成される。「偉大なワインの歴史が始まる」** |
| **1716** | **Alexandre de Ségur が死の直前に Lafite を取得** |
| **1718** | **息子 Nicolas-Alexandre（ルイ 15 世に「`Prince des Vignes`（ブドウ畑の公）」と呼ばれた、ボルドー高等法院院長）が Mouton と Calon の土地を取得** |
| 🔴 **1714 / 1729 / 1767** | 🔴 **価格倍率の公式記録。**「**1714 年に Latour の 1 トノーは並のボルドー 1 トノーの 4〜5 倍。1729 年にはその比は 13 倍、1767 年には 20 倍**」 |
| **1759 / 1794** | **ブドウ畑が 38 ヘクタール（1759）→ 47 ヘクタール（1794）へ** |
| **1787** | 🏛 **INAO の cahier des charges 自身が記す**:「**1787 年、Thomas Jefferson の作成した格付は Latour と Lafite を premiers crus に置いている**」 |
| **革命期** | **所領は苦労の末に一体性を保ち、しかも同じ家族の手に残った** |
| **1842** | **相続により共有者が増えたため、共有者たちが Société Civile を結成。1962 年までこの会社は Ségur 家の子孫のみで構成される** |
| 🔴 **1855** | 🔴 **この唯一無二のテロワールが 1er cru に格付けされる**（公式本文の表現は「**classé 1er cru en 1855**」）。**同じ組には Lafite-Rothschild、Margaux、Haut-Brion、そして 1973 年から Mouton-Rothschild が入る** |
| **1962 以降** | **相続人の激増により持分の大半が売却される。英国の金融グループ `Pearson` が 53% の筆頭株主となり、`Harveys of Bristol`（のち `Allied Lyons` に買収される）が 25% を取得** |

| 🔴 **1993 年 6 月** | 🔴 **François Pinault 氏が持株会社 Artémis を通じて Allied Lyons の持分を取得** |
| **1995 初頭 / 1998** | **Frédéric Engerer が入社（1995 初頭）、1998 年に Gérant に任命** |
| **1999-11 〜 2003-09** | **大規模改修。**熟成庫・醸造棟・醸造設備・貯蔵区画の全面刷新。**技術チームも一新** |
| **2001** | **醸造棟（cuvier）の全面改修**。以後 **164 hl 〜 12 hl の異なる容量のステンレスタンク 80 基超** |
| 🔴 **2007（ミレジム）** | 🔴 **`Prooftag` によるトレーサビリティ／真正性認証システムを導入**（数年の試験を経て）。**2007 ミレジム以降の全ボトルのキャップシールに照会コードが付される** → §Open Questions 1 |
