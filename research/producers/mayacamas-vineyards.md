## Overview

✅ **Napa Valley の Mt. Veeder の山上にある、1889 年創業のワイナリー。**
**現在の建物は創業者が敷地から集めた石で建てたものをそのまま使っている。**

🔴 ✅ **公式が繰り返す自己規定は「山のブドウ（mountain grown）」である。**
「**険しい地形と強い日射が複数の微気候を生み、そこで Cabernet Sauvignon は幅のある風味の輪郭を発達させる。**」

🔴 ✅ **クローンの選択に伝統がある。**
「**伝統に従い、植栽は California の heritage クローン選抜が主体である ——
`Sees`、`Martha's`、`Niebaum`、`Martini`、そして自家の `Mayacamas house clone` を含む。**」
（Chardonnay は **`Wente` クローンの複数の変異体を `St. George` 台木に**。）

🔴 ✅ **2013 年から有機栽培。**（**認証の有無・認証機関名は公式に記載が無い** → §Farming）

## History

| 年 | 出来事 ✅ |
|---|---|
| **1889** | 🔴 **John Henry Fisher がこの人里離れた山上の土地を購入し、いまも使っているワイナリーを建てる。**<br>**ワイナリーと近くの蒸留所を敷地で集めた石で建て、Zinfandel を植え、`Fisher & Sons` と名づけた。**<br>**ワインは樽で売り、危険な山道を馬車で Napa 川まで下ろし、艀でサンフランシスコへ運んだ** |
| **1906** | 🔴 **サンフランシスコ大地震と大火で Fisher の事業が破産。Mount Veeder の地所は Napa 郡庁舎の階段で $5,000 で競売にかけられた** |
| **1941** | 🔴 **Jack and Mary Taylor が土地を購入し `Mayacamas Vineyards` と改称。**<br>**いまも使っているワインラベルと古典的な図像を作ったのもこの夫妻である** |
| **1950 年代** | **Taylor 夫妻がより近代的な発酵室を建て、大型のオーク・カスクの在庫を拡張。**<br>🔴 **最も長く残る功績は畑にあり、Jack がこの地所に最初の Chardonnay と Cabernet Sauvignon を植えた** |
| **1968** | 🔴 **所有が Bob and Elinor Travers へ。Bob は当時 30 歳、`Heitz Cellars` での修業から伝統的醸造への揺るぎない傾倒を既に備えていた** |
| **1976** | 🔴 **Travers の 1971 年ヴィンテージが「パリスの審判」に選ばれた。**<br>「**この国際的な催しが、カリフォルニアのワイン造りの品質に正統性を与えた。**」 |
| （その後） | **Bob の伝統的手法は 45 ヴィンテージ・6 つの十年にわたり一貫し、「Mayacamas の伝説のどの章にも劣らず不可欠な、唯一無二の醸造スタイル」を生んだ** |
| **2013** | 🔴 **畑が有機栽培に**（全ワインページの記述） |

## Winemaking

### 🔴 Cabernet Sauvignon ✅

| 工程 | 公式の記述 |
|---|---|
| 発酵容器 | 🔴 **コンクリート槽・ステンレス槽・オーク容器の組み合わせ** |
| 作業 | **毎日のポンプオーバーと撹拌で温度を均一化し、果皮から色と風味を抽出** |
| **発酵＋醸し** | 🔴 **通常 10〜25 日（風味次第）** |
| **発酵温度** | 🔴 **低め。ピーク時で最高 78 °F 前後** |
| **熟成①** | 🔴 **大型フードルで 24 か月。容量 185 gallons（700 L）〜1,200 gallons（45 HL）。フレンチとアメリカンの混成で、よく使い込まれており、なかには 100 年近いものもある** |
| **熟成②** | 🔴 **さらに 12 か月を 60 gallon（225 L）バリックと 132 gallon ピュンション（500 L）で。通常 新フレンチオーク 10%** |
| **総熟成** | 🔴 **36 か月** |
| **瓶熟** | 🔴 **リリース前に 1 年** |
| ブレンド | **ヴィンテージにより変わる。100% Cabernet Sauvignon の年もあれば、Cabernet Franc / Merlot を含む年もある** |

### 🔴 Red Wine（＝ OBP の `Proprietary Blend`）✅

| 工程 | 公式の記述 |
|---|---|
| 位置づけ | 🔴 **「左岸ボルドーに着想を得たブレンド。Cabernet Sauvignon を主役に、Merlot と Cabernet Franc が重要な脇役を務める」** |
| 発酵 | **区画と目指す抽出の輪郭に応じて、コンクリート・ステンレス・オーク容器を使い分ける** |
| **発酵＋醸し** | **通常 10〜25 日。発酵温度は中庸で、活発な発酵時におよそ 80 °F** |
| **熟成①** | 🔴 **大型フードルで 12 か月。容量 330 gallons（1,200 L）〜1,200 gallons（45 HL）。フレンチ・アメリカン・**オーストリアン**の混成。よく使い込まれており、なかには 100 年近いものも** |
| **熟成②** | **さらに 12 か月を 60 gallon（225 L）バリックと 158 gallon ピュンション（600 L）で** |
| **総熟成** | 🔴 **24 か月** ／ **瓶熟 1 年** |
| ブレンド | **ヴィンテージにより変わるが通常 Cabernet Sauvignon 主体。Cabernet Franc が香りの持ち上げと精確さを、Merlot が中盤の幅と質感を与える** |

### 🔴 Chardonnay ✅

| 工程 | 公式の記述 |
|---|---|
| **圧搾** | 🔴 **全房圧搾 85% ＋ 破砕圧搾 15% を、横型タンクプレスで低圧にて** |
| 清澄 | **ステンレスで低温のジュース沈降と清澄** |
| 発酵 | **澱引き後にオーク容器へ移して**アルコール発酵。**通常 2〜4 週間、カーヴの温度で** |
| **バトナージュ** | 🔴 **発酵が遅い場合に用いることがあるが、通常は行わない** |
| 🔴 **マロラクティック** | 🔴 **`Malolactic fermentation is prohibited.`（禁止している）** |
| **熟成** | 🔴 **通常 45% をピュンションとフードル（132 gallon / 500 L 〜 264 gallon / 1,000 L。フレンチとオーストリアン）で、残り 55% を 60 gallon（228 L）バリックで** |
| **新樽** | 🔴 **通常 ヴィンテージあたり樽の 10% が新樽** |
| **総熟成** | 🔴 **12〜18 か月（ヴィンテージ次第）** ／ **瓶熟 1 年** |
